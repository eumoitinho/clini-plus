# API CLINIPLUS

Esta seção descreve os endpoints REST do MVP. Todos os endpoints são hospedados sob `/api` no Next.js.

## Padrões
- Respostas JSON com status HTTP apropriado.
- Validação de payloads com Zod.
- Autenticação via NextAuth e Azure AD B2C.
